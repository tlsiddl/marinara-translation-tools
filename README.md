# 번역 프리셋·단어장 (기억 서재 호환)

[Marinara Engine](https://github.com/Pasta-Devs/Marinara-Engine)용 개인 확장 「번역 프리셋·단어장」 1.6.4를 바탕으로 고친 버전입니다.
AI 번역 프리셋, 채팅별 단어장·대사 지침·기타 지침, 문단별 번역 보기, 대조·수정, 말투·단어 자동 수집, 설정 백업 기능은 원본 그대로 쓸 수 있습니다.
[기억 서재 (장기 기억 모듈)](https://github.com/tlsiddl/marinara-memory-module)와 함께 쓰도록 맞췄습니다. 따로 써도 됩니다.

> 비공식 확장입니다. 원본 확장 작성자나 Marinara Engine·Pasta-Devs와 관련이 없습니다. 설명과 테스트의 예시 인물·대사는 모두 지어낸 것입니다.

## 기억 서재와 함께 쓰기

기억 서재 0.14.0 이상과 함께 설치하면 아래가 저절로 됩니다. 이 확장에서 따로 켤 것은 없습니다.

- **단어장 → 기억 번역**: 기억 서재가 방을 열 때 이 확장에 저장된 그 방의 단어장(없으면 기본 단어장)에서 `영어 = 한국어` 짝을 가져갑니다. 영어로 정리된 기억을 한국어로 보여 줄 때 이름을 단어장대로 적고, 사람 이름이면 기억 모듈의 이름 정리 표에 그 사람의 다른 이름으로 넣어 같은 사람으로 묶습니다.
- **응답 번역 → 한국어 낱말 회상**: 자동 번역으로 저장된 캐릭터 응답의 한국어 번역을 기억 모듈이 읽어, 한국어로 쓴 메시지의 낱말로 지난 원문을 찾을 때 씁니다. 번역은 찾기에만 쓰고 기억 내용에는 넣지 않습니다.
- **입력 번역**: 입력을 영어로 번역해서 보내면 마리나라에는 번역된 영어만 저장됩니다. 기억 모듈은 한국어 입력은 기억의 한국어 번역으로, 영어 입력은 영어 낱말로 찾으므로 어느 쪽으로 보내도 됩니다.
- 마리나라에 설치되는 확장 이름은 원본과 같은 「번역 프리셋·단어장」입니다. 그래서 이미 설치한 것 위에 그대로 업데이트되고, 설정·단어장도 그대로 이어집니다.

## 바뀐 점

### 프리셋 2종 추가
캐릭터 응답 번역용으로 세 프리셋이 들어 있습니다. 모두 아래 원칙을 따릅니다.

- 지시 대상이 분명하면 `she/her` 등을 인물 이름으로 옮기거나 자연스럽게 생략하고, 습관적인 `그/그녀/그의/그녀의`는 줄입니다. 대상이 모호하면 임의로 정하지 않습니다.
- 원문의 문체·호흡·서술 시점과 인물별 말투(존댓말·반말·호칭·어미)를 살립니다.
- 대사 지침의 `- 사용 언어:` 줄을 보고, 외국어를 쓰는 인물의 대사를 `"외국어 대사" (한국어 번역)` 형태로 표시합니다. 사용 언어가 한국어거나 비어 있거나 `(추정)`이면, 또는 화자가 불분명하면 한국어로만 번역합니다.

| 프리셋 | 외국어 대사를 표시하는 경우 |
| --- | --- |
| 한국어 문체·이름 중심·외국인 대사 병기 (원문 있을 때만) | 원문 대사가 그 인물의 언어로 적혀 있을 때만. 외국어 대사를 새로 만들지 않음 |
| 한국어 문체·이름 중심·외국인 대사 병기 (외국어 대사 생성) | 원문이 다른 언어여도 그 인물의 언어로 옮겨 적고 한국어 번역을 붙임 |
| 한국어 문체·이름 중심·모델 병기 유지 (지문만 번역) | 모델이 이미 쓴 한국어 대사·`"원어" (한국어 번역)` 병기 대사는 그대로 두고 지문만 번역. 한국어가 없는 대사만 한국어로 옮김 |

- 두 프리셋은 대사 지침을 꺼 두어도 현재 채팅의 유저 페르소나 이름을 번역 요청에 함께 보냅니다. 페르소나를 가리키는 `she/her` 등은 이 이름으로 옮기거나 생략합니다.
- 대사 지침이 없는 인물은 한국어 화자로 봅니다. 사용 언어에 한국어와 다른 언어가 함께 있으면, 원문 대사가 그 다른 언어일 때만 병기합니다.

### 기타 지침 저장해서 다른 채팅에서 쓰기
기타 지침 칸 아래에서 지금 쓴 지침을 이름을 붙여 저장하고, 다른 채팅에서 골라 **불러오기**를 누르면 그 채팅의 기타 지침이 그 글로 바뀌고 바로 저장됩니다. 같은 이름으로 다시 저장하면 그 지침을 고칩니다. 저장한 지침은 모든 채팅이 함께 쓰고, 나중에 고치거나 지워도 이미 불러온 채팅의 기타 지침은 그대로입니다. 전체 백업에도 들어갑니다.

### 한국어로 내는 기본 프리셋: 한글로만
한국어로 번역하는 기본 프리셋(한국어 문체 3종, 영어·중국어·일본어→한국어, 원문 대사 병기, 의역·번역체)의 끝에 "한글로만 쓰고 한자·일본 가나를 섞지 않는다"는 줄을 넣었습니다. 모델이 번역문에 중국어 낱말을 섞는 일을 줄입니다. 그대로 두라고 한 원문 대사·외국어 병기 대사·꼬리표·§RP 줄은 예외입니다. 대상 언어를 고르는 범용 프리셋과 인풋용 프리셋은 그대로입니다.

### 놓친 자동 번역 보충
답변 생성 중에 화면이 꺼지거나 연결이 끊기면 답변은 저장되지만 자동 번역이 시작되지 않습니다. 이제 채팅을 열거나 페이지로 돌아왔을 때, 자동 번역이 켜진 채팅의 최신 답변이 30분 안에 생성됐고 번역이 하나도 없으면 그 답변을 번역합니다.

### 번역을 고치면 영어 원문도 고치기
대조·수정 창의 **영어 원문도 같이 고치기**를 켜고 저장하면, 직접 고친 문단마다 모델이 이전 번역과 고친 번역을 비교해 영어 원문에서 바뀐 부분만 고쳐 메시지에 저장합니다. 고친 번역은 새 원문에 그대로 연결됩니다. 다시 번역(AI) 결과는 대상이 아니며, 번역 연결이 지정되어 있어야 합니다.

### 채팅 전환 감지를 상시 확인에서 이벤트 방식으로 변경
원본은 0.25초마다 현재 채팅을 확인했습니다. 이제 화면이 바뀌거나 페이지 주소가 바뀔 때만 확인합니다.

### 말투 자동 정리에 사용 언어·페르소나 표시 추가
- 캐릭터 카드·페르소나·로어북에서 인물별 사용 언어를 찾아 `- 사용 언어: 영어 (한국어는 서툶)`처럼 적습니다.
- 국적이나 출신만 있고 언어가 명시되지 않았으면 `(추정)`을 붙입니다. 확인한 뒤 `(추정)`을 지우면 확정으로 취급됩니다.
- 유저 페르소나 항목에는 `- 역할: 유저 페르소나`가 붙습니다.
- 결과는 대사 지침에 저장되므로 기존 편집기에서 확인·수정할 수 있습니다.

### 기본 번역 버튼도 최신 프리셋 사용
위 두 프리셋을 고른 경우, 마리나라 설정칸에 예전 프롬프트가 남아 있어도 확장에 들어 있는 최신 프롬프트로 번역합니다.

## 설치
`personal-extension` 폴더(`manifest.json`, `extension.js`)를 마리나라의 개인 확장으로 추가합니다.

## 사용 방법
1. 채팅 설정의 번역 항목에서 캐릭터 응답 프리셋으로 위 두 프리셋 중 하나를 고릅니다.
2. **말투 자동 정리**를 실행하고, 결과에서 사용 언어를 확인·수정합니다. 이렇게 하면 대사 지침이 켜집니다.
   - 대사 지침이 꺼져 있으면 사용 언어 정보가 번역에 전달되지 않습니다.
   - 이전에 만든 대사 지침에는 사용 언어 줄이 없으니, 다시 정리하거나 `- 사용 언어: 영어`처럼 직접 넣어 주세요.

## 기타 지침 예시

[`기타 지침/지문 문체.txt`](기타%20지침/지문%20문체.txt)는 영어 지문을 번역체 없이 한국어 웹소설 문체로 옮기도록 하는 기타 지침입니다. 채팅 설정 → 번역 확장의 **기타 지침**에 붙여 넣고 켜 주세요.

- 3인칭 근접 시점의 자유간접화법, 연결 어미로 문장 잇기, 번역체 표현(~에 대해, 그는/그녀는, ~의 반복) 피하기
- 원문의 논리·숫자·단위·신체 묘사를 그대로 지키고, 원문에 없는 수식어나 행동을 더하지 않기
- 영어로 쓴 숫자는 아라비아 숫자 + 한국어 단위로(32도, 5킬로그램)
- 제/자기가 엉뚱한 사람을 가리키지 않게 소유자 이름 쓰기, 자주 틀리는 낱말(목/목덜미 등) 정리
- 「계집」 금지

19금 장면용 문체 지침은 이 저장소에 올리지 않고 따로 배포합니다: [19금 여성향 문체 (구글 드라이브)](https://drive.google.com/file/d/1oPvShA_V9u_fY0vkNmWxm5F2LzKdnE-R/view?usp=sharing). 받으신 분은 위 지침 **아래에 이어 붙여** 쓰시면 됩니다. 성인 이용자만 받아 주세요.

예시 속 인물 이름(도하, 서연 등)은 규칙을 보여 주려고 지어낸 것이라 그대로 두셔도 됩니다.

## 테스트
`tests/test.js`는 Playwright로 확장을 가짜 마리나라 환경에서 실행해, 말투 정리 결과 변환과 번역 요청에 들어가는 프롬프트를 확인합니다. `tests/notes.test.js`는 기타 지침 저장·불러오기·지우기와 한글로만 줄이 붙는 프리셋을 확인합니다.

```sh
node tests/test.js personal-extension/extension.js
node tests/auto-translate.test.js personal-extension/extension.js
node tests/notes.test.js personal-extension/extension.js
```

실제 마리나라에서의 동작과 번역 품질은 직접 확인이 필요합니다.

## 라이선스
`extension.js`에는 Marinara Engine 코드 일부(AGPL-3.0)가 포함되어 있습니다.
